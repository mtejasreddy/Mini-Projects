# 📝 Markdown Previewer

A React application that lets you type **Markdown text** and instantly see the **formatted HTML output** side‑by‑side.  
This project demonstrates **React state management, controlled components, and third‑party library integration**.

---

## 🚀 Features

- Real‑time Markdown to HTML conversion
- Side‑by‑side editor and preview layout
- Responsive design with clean styling
- Supports headings, bold, italic, lists, links, and code blocks

---

## 🛠️ Tech Stack

- **ReactJS** – component-based UI
- **Marked.js** – Markdown parser
- **CSS Flexbox** – responsive layout

---

## 🎮 How to Run

1. Clone the repository:
   git clone https://github.com/mtejasreddy/Mini-Projects.git
   - cd markdown-previewer
2. npm install
3. npm start
